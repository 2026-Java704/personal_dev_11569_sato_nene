# 修正・追加したこと

## 薬登録まわり
- 薬追加画面で最初に登録画面へ行ける流れを整理しました。
- 薬名は100種類の候補から選べるようにし、候補にない時だけ手入力もできるようにしました。
- 個数入力を残しつつ、別で「処方薬 / 市販薬」を選べるようにしました。
- 備考とは別に「朝 / 昼 / 夜」と「食前 / 食後」を選べるようにしました。
- 日付は「飲み始め日」として登録する形にしました。
- 飲んだ時間は追加時には入れず、済チェックを押した時に自動で保存するようにしました。

## 薬管理画面
- 未服用の薬だけを表示する薬管理画面にしました。
- 薬管理画面から更新・削除ができるようにしました。
- 済チェックを入れると、その薬は薬管理画面から消えて服用履歴へ移動するようにしました。

## 服用履歴画面
- 服用した薬だけを表示する一覧画面を追加しました。
- 一覧では「薬名・個数・服用時間」を確認できます。
- 済チェックを外すと、薬管理画面へ戻るようにしました。

## コード側
- `Medicine` に薬の種類、朝昼夜、食前食後、服用時間を持てるように項目を追加しました。
- `schema.sql` と `data.sql` を今の画面項目に合わせて更新しました。
- `README.md` に今回の修正内容だけを残しました。
